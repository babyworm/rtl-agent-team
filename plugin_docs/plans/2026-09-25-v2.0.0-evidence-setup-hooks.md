## Per-claim notes

### #3 env_source
- `env_source` is used only during detection. `tool-runner.sh:136/204` resolves tools with `command -v` only, and `agents/equivalence-checker.md:87-89` refuses to evaluate rat_config strings.
- Detection falls back to PATH (GC:100-106), so launching `claude` from an already-sourced tcsh session works by accident. PATH is persisted only to `~/.profile` (`install-commands.md:111-112`), which tcsh does not read.

- The licence probe already uses `sg_shell -help </dev/null` (`tool-runner.sh:232`) and `vc_static_shell` gets `-batch` (`run_cdc.sh:293-294`); SpyGlass got neither.
- Under `set -euo pipefail` a non-zero exit aborts before the summary, so a silent pass needs exit 0 — the prompt/EOF path. The trailing Tcl `exit` is skipped after any Tcl error (`run_lint.sh:243`, `run_cdc.sh:266`).
- `run_goal` violations never change the exit status, so clean exits pass with real lint/CDC errors. `lint-tool-profiles:32-33` and `cdc-tool-profiles:102-104` promise normalisation the runners do not do.

### F1 — Stop gates end the turn
- `emit_stop_block` (`hooks/lib/hook-output-util.sh:27-31`) sends `continue:false` with `decision:"block"`. The hooks reference: "`continue: false` takes precedence over `decision: "block"`, so if you set both, `continue: false` wins and Claude stops." The 2.1.282 Stop runner returns `preventContinuation:true`, reason `stop_hook_prevented`.
- Pinned by 39 `continue … is False` assertions in `tests/unit/test_hooks.py` and by `plugin_docs/hook-development-guide.md:86`.
- `emit_block` (:19-23) adds `continue:false` to PreToolUse denies, which halts the whole turn instead of denying one call.
- Needs one live confirmation (`claude --debug`) before the rewrite.

### F2 — Typed slash commands bypass PreToolUse(Skill)
- A typed `/rtl-agent-team:<skill>` is expanded client-side; 2.1.282 fires `UserPromptExpansion` (`expansion_type: "slash_command"`, `command_name`, `args`), not the Skill tool. `hooks.json` registers neither UserPromptExpansion nor UserPromptSubmit.
- For typed commands these never engage: `skill-active.json` (completion loop), `compliance-state.json`, the spawn-context manifest, the P5B entry block (`rtl-phase-state-bootstrap.sh:129-151`).
