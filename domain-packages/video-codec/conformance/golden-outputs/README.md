# Conformance Golden Outputs

This directory stores golden (reference) decoder outputs for conformance verification.

## How to Generate

Golden outputs are generated by running the official reference software on conformance bitstreams.

### H.264 (JM Reference Software)
```bash
# Build JM
cd JM && mkdir build && cd build && cmake .. && make

# Generate golden output (YUV 4:2:0)
./ldecoder -i ../test-vectors/h264/CVPCMNL1_SVA_C.264 -o golden_CVPCMNL1.yuv
```

### H.265 (HM Reference Software)
```bash
# Build HM
cd HM && mkdir build && cd build && cmake .. && make

# Generate golden output
./TAppDecoder -b ../test-vectors/h265/DBLK_A_SONY_3.bin -o golden_DBLK_A_SONY_3.yuv
```

## Directory Structure
```
golden-outputs/
├── h264/
│   ├── golden_CVPCMNL1.yuv
│   ├── golden_CVPCMNL1.md5    # MD5 checksum for quick verification
│   └── ...
├── h265/
│   ├── golden_DBLK_A_SONY_3.yuv
│   ├── golden_DBLK_A_SONY_3.md5
│   └── ...
```

## Verification

Compare RTL decoder output against golden:
```bash
md5sum -c golden_outputs/h264/golden_CVPCMNL1.md5
# or bit-exact binary comparison:
cmp rtl_output.yuv golden_outputs/h264/golden_CVPCMNL1.yuv
```
